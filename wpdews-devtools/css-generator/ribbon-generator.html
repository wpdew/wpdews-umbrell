📚 Про CSS Ribbon Generator

            
CSS Ribbon Generator - інструмент для створення стильних CSS стрічок, відзнак та тегів для сайту.

            
            
🎨 Типи стрічок:

            
    
                
  • Corner Ribbons - кутові стрічки (top-left, top-right, bottom-left, bottom-right)
    • 
                
  • Side Ribbons - бокові стрічки (left, right)
    • 
                
  • Center Ribbons - центральні стрічки (top, bottom)
    • 
                
  • Bookmark - стрічка-закладка з загнутим краєм
    • 
            


            
💡 Використання:

            
    
                
  • "NEW" - позначка нових товарів або функцій
    • 
                
  • "SALE" - акційні пропозиції та знижки
    • 
                
  • "TOP" - популярні товари
    • 
                
  • "FREE" - безкоштовні послуги
    • 
                
  • Будь-який текст - відзнаки, рейтинги, статуси
    • 
            


            
🔧 Налаштування:

            
    
                
  • 9 готових типів розташування стрічки
    • 
                
  • Довільний текст та розмір шрифту
    • 
                
  • Налаштування кольорів фону та тексту
    • 
                
  • Padding та border-radius для кастомізації
    • 
                
  • Box-shadow для об'ємного ефекту
    • 
            


            
⚡ Технічні деталі:

            
    
                
  • Використовує position: absolute для позиціонування
    • 
                
  • CSS transform для кутових стрічок
    • 
                
  • Псевдоелемент ::after для bookmark ефекту
    • 
                
  • Батьківський елемент повинен мати position: relative
