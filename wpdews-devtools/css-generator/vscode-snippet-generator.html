VSCode Snippet Generator

Генеруйте snippets JSON для Visual Studio Code в реальному часі

Працює повністю локально: підтримка префіксу, опису, scope мов, tabstops, placeholders, а також декількох snippet-блоків в одному файлі .code-snippets.

Використовуйте placeholders: ${1:name}, ${2:value}, фінальна позиція курсора: $0.

Формат VS Code snippets

Кожен елемент має структуру: name → { prefix, scope, body, description }.

  • prefix: що вводити в редакторі для автодоповнення.
  • scope: мови через кому, наприклад javascript,typescript.
  • body: масив рядків; переноси рядків у вашому input автоматично перетворюються у масив.
