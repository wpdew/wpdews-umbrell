Про Data URI

Data URI (Data URL) - це схема, яка дозволяє вбудовувати файли безпосередньо в HTML або CSS за допомогою Base64 кодування. Це усуває необхідність в окремому HTTP запиті для зображення.

Переваги:

  • Зменшення кількості HTTP запитів
  • Швидше завантаження невеликих зображень
  • Зображення завжди доступне з HTML/CSS
  • Не потрібен окремий файл

Недоліки:

  • Збільшення розміру файлу на ~33% через Base64
  • Неефективно для великих зображень (>10KB)
  • Погана кешуємість
  • Складність читання та редагування коду

Рекомендації: Використовуйте Data URI для маленьких іконок, логотипів та декоративних елементів розміром до 1-2 KB. Для великих зображень краще використовувати звичайні файли з оптимізацією та кешуванням.
