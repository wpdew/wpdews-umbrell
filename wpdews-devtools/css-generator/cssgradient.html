Про CSS Градієнти

CSS градієнти - це плавні переходи між двома або більше кольорами. Вони є частиною типу даних image і можуть використовуватись скрізь, де можна використати зображення, найчастіше як фон елемента.

Linear градієнти створюють перехід кольорів уздовж прямої лінії, визначеної кутом або напрямком. Вони найпопулярніші в сучасному веб-дизайні.

Radial градієнти створюють перехід, що виходить з центральної точки. Можуть бути круглими (circle) або еліптичними (ellipse).
