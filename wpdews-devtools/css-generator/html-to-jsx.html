Convert HTML to JSX (React)

Вставляйте HTML зліва та отримуйте готовий JSX справа в реальному часі

Конвертація виконується локально у браузері: атрибути автоматично адаптуються під React, включно з className, htmlFor, camelCase style та boolean props.

Порада: якщо у вхідному HTML кілька кореневих елементів, JSX автоматично обгорнеться у Fragment.
