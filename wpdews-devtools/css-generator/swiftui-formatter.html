💡 Довідка: Використання локальних зображень замість AsyncImage

У SwiftUI для картинок, які знаходяться всередині додатка, AsyncImage не потрібен. Найпростіший варіант — покласти зображення в Assets.xcassets і використовувати Image("назва_картинки").

  1. Додайте картинку в Assets:
    В Xcode відкрийте Assets.xcassets → + → Image Set.
    Наприклад, назвіть її: lessonImage і перетягніть туди файл зображення.
  2. Замість AsyncImage використовуйте Image:
    Приклад коду для локального зображення: 
import SwiftUI

struct GeneratorView: View {
    var body: some View {
        ScrollView {
            VStack(alignment: .leading, spacing: 12) {

                Text("Привет мир")
                    .font(.body)
                    .foregroundColor(.white.opacity(0.9))
                    .lineSpacing(4)

                Image("lessonImage")
                    .resizable()
                    .aspectRatio(contentMode: .fit)
                    .frame(maxWidth: .infinity)
                    .clipShape(RoundedRectangle(cornerRadius: 12))
            }
            .padding(24)
            .frame(maxWidth: .infinity, alignment: .leading)
        }
        .background(Color.devMainBg)
    }
}
