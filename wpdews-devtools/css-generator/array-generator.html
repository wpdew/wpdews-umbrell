Array Generator - JSON & PHP

Створюйте JSON та PHP масиви з динамічної таблиці

📋 Як використовувати

1. Перший рядок: Назви ключів масиву (редагуються)

2. Наступні рядки: Значення для кожного елемента масиву

3. JSON підтримка: Якщо значення починається з [ або { - автоматично розпарситься як JSON

4. Генеруйте: Натисніть "Generate JSON" або "Generate PHP" для отримання коду

Приклади JSON у полях (вводьте без екранування):
["images/ggh.jpg","images/art3.jpg"]
["Класичний","Бронзовий","Зелений шинель"]
[{"size":"90 см","new_price":"2350","old_price":"2960"}]

💡 Підказки

            
Редагування заголовків: Натисніть на назву колонки щоб змінити ключ масиву

            
JSON у полях: Можна вводити масиви ["a","b"] або об'єкти {"key":"value"}

            
JSON Format: Автоматично генерує правильний JSON з екранованими слешами \/

            
PHP Format: Генерує PHP масив з правильним синтаксисом та екрануванням

            
Кнопка ×: У заголовку видаляє всю колонку, у рядку - видаляє рядок
