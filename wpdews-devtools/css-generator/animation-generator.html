📚 Про CSS Animation Generator

            
CSS Animation Generator - інструмент для створення CSS анімацій з візуальним попереднім переглядом.

            
            
🎯 Основні можливості:

            
    
                
  • 16 пресетів анімацій - готові ефекти (fade, slide, bounce, rotate тощо)
    • 
                
  • Налаштування параметрів - duration, delay, iteration, timing, direction, fill-mode
    • 
                
  • Live Preview - миттєвий перегляд анімації
    • 
                
  • Готовий CSS код - з @keyframes та animation властивостями
    • 
                
  • Копіювання в один клік - швидке використання в проекті
    • 
            


            
💡 Timing Functions:

            
    
                
  • ease - плавний старт та фініш (за замовчуванням)
    • 
                
  • linear - рівномірна швидкість
    • 
                
  • ease-in - повільний старт
    • 
                
  • ease-out - повільний фініш
    • 
                
  • ease-in-out - повільний старт та фініш
