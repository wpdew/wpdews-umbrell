Про Clip Paths

Властивість clip-path дозволяє створювати складні форми в CSS, обрізаючи елемент до базової фігури (коло, еліпс, багатокутник або inset), або до SVG джерела.

CSS анімації та переходи можливі з двома або більше clip-path фігурами, які мають однакову кількість точок.
