📚 Про CSS Flexbox Generator

            
CSS Flexbox Generator - візуальний редактор для створення гнучких макетів з використанням CSS Flexbox.

            
            
🎯 Властивості контейнера:

            
    
                
  • flex-direction - напрямок розташування елементів (row, column)
    • 
                
  • flex-wrap - перенесення елементів на новий рядок
    • 
                
  • justify-content - вирівнювання по головній осі
    • 
                
  • align-items - вирівнювання по перпендикулярній осі
    • 
                
  • align-content - вирівнювання ліній при wrap
    • 
                
  • gap - проміжок між елементами
    • 
            


            
🎨 Властивості елементів:

            
    
                
  • flex-grow - коефіцієнт збільшення (як елемент займає вільний простір)
    • 
                
  • flex-shrink - коефіцієнт зменшення (як елемент зменшується)
    • 
                
  • flex-basis - базовий розмір елемента (auto, 100px, 50% тощо)
    • 
                
  • align-self - індивідуальне вирівнювання елемента
    • 
                
  • order - порядок відображення елемента
    • 
            


            
💡 Корисні поради:

            
    
                
  • Клікніть на елемент щоб налаштувати його індивідуальні властивості
    • 
                
  • flex-grow: 1 на всіх елементах - рівномірний розподіл простору
    • 
                
  • flex-wrap: wrap - дозволяє елементам переноситись на новий рядок
    • 
                
  • gap замінює margin між елементами (підтримка в сучасних браузерах)
