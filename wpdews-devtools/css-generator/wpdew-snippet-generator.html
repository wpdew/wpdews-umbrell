Wpdew Snippet Generator

Генератор для формату snippets.json (Code Snippets Inserter)

Створює snippet у форматі name -> code + description. Код автоматично екранується: \n, \t, \" і \$ для PHP-змінних.

Підтримка placeholder: ${1:text}, ${2:value}, $0. Для PHP змінних у результаті автоматично буде \$.

Output

Формат для code-snippets-inserter

Цей генератор створює формат:

"Snippet Name": {
  "code": "line1\\nline2\\nline3",
  "description": "Some description"
}
