📚 Про CSS Column Generator

            
CSS Column Generator - інструмент для створення багатоколонкових текстових макетів з використанням CSS Multi-column Layout.

            
            
🎯 Основні властивості:

            
    
                
  • column-count - кількість колонок (1-6)
    • 
                
  • column-width - мінімальна ширина колонки
    • 
                
  • column-gap - проміжок між колонками
    • 
                
  • column-rule - вертикальний роздільник між колонками (width, style, color)
    • 
                
  • column-fill - розподіл контенту (balance/auto)
    • 
                
  • column-span - елемент на всю ширину (наприклад заголовок)
    • 
            


            
💡 Корисно знати:

            
    
                
  • Auto Width - браузер автоматично визначає ширину колонок
    • 
                
  • Balance - намагається зробити колонки однакової висоти
    • 
                
  • Column Span: All - для заголовків, які займають всю ширину
    • 
                
  • Підтримка браузерів - всі сучасні браузери (з префіксами для старих версій)
    • 
            


            
🎨 Приклади використання:

            
    
                
  • Газетні макети з багатьма колонками тексту
    • 
                
  • Блоги та статті з покращеною читабельністю
    • 
                
  • Pinterest-подібні сітки (masonry layout)
    • 
                
  • Списки елементів у декілька колонок
